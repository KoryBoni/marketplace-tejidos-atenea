# Manual de usuario - Marketplace Tejidos Atenea

## Acceso al sistema

Abrir la aplicacion en:

```text
http://localhost:5173
```

## Usuario cliente

### Registro

1. Entrar a `Crear cuenta`.
2. Ingresar nombre, correo y contrasena.
3. Enviar el formulario de registro.

### Inicio de sesion

1. Entrar a `Entrar`.
2. Escribir correo y contrasena.
3. Acceder al sistema.

### Consultar productos

1. Entrar a `Tienda`.
2. Revisar el catalogo disponible.
3. Usar busqueda, categorias o rango de precio para filtrar productos.
4. Abrir un producto para ver la informacion ampliada.

### Favoritos

1. Marcar un producto con el icono de corazon.
2. Entrar a `Favoritos`.
3. Revisar los productos guardados.

### Carrito y pedido

1. Agregar productos al carrito.
2. Revisar cantidades y total.
3. Finalizar pedido.
4. Ingresar nombre, telefono, direccion y metodo de pago.
5. Confirmar el pedido.

### Mis pedidos

1. Iniciar sesion como cliente.
2. Entrar a `Mis Pedidos`.
3. Revisar estado, fecha y total del pedido.

## Usuario administrador

### Acceso al panel

1. Iniciar sesion con una cuenta administradora.
2. Entrar a `Admin`.
3. Revisar el dashboard general.

### Gestion de productos

El administrador puede crear, editar, desactivar y reactivar productos. En cada producto puede registrar nombre, descripcion, precio, stock, categoria e imagen.

### Gestion de categorias

El administrador puede crear, editar y eliminar categorias para organizar el catalogo.

### Gestion de pedidos

El administrador puede revisar pedidos y actualizar su estado segun el proceso de venta.

## Mensajes del sistema

El sistema muestra mensajes cuando faltan datos de entrega, cuando el carrito esta vacio o cuando el catalogo no puede cargarse porque el backend no esta activo.
